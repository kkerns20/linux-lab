# Linux Lab

Hands-on Linux learning through self-hosting, Raspberry Pi, networking, automation, and home lab projects.

## Projects

- **[YAMS Media Server](https://github.com/kkerns20/yams-media-server)** — Docker, self-hosting, VPN networking, media services, Plex, and troubleshooting
- **[Home Server Roadmap](projects/home-server-roadmap.md)** — current hardware inventory, permanent-server plan, storage growth, and future migration
- **Pi-hole** — Network-wide ad blocking and DNS management
- **Raspberry Pi Builds** — Practical Raspberry Pi projects and experiments
- **Home Lab Experiments** — Linux, networking, automation, and self-hosted tools

## Current lab direction

The current YAMS environment is running on a Dell Latitude 7480 with Ubuntu 24.04. The laptop remains useful for learning, VMs, and administration, but the long-term plan is to move always-on services to a permanent wired mini PC or small-form-factor system and attach expandable bulk storage separately.

The goal is to preserve stable service paths such as `/srv/media` while evolving the hardware underneath them.

## Goals

- Build practical Linux skills through real projects
- Learn Git and GitHub through regular use
- Document setup steps, troubleshooting, and lessons learned
- Explore self-hosting, networking, automation, and home-server tools
- Build a permanent home server with expandable storage
- Learn migration, backup, monitoring, and recovery rather than treating installations as disposable
